# nue-host changelog

## [0.1.0] - 2026-11-10

### Fixed

- **Безопасность: обход корня через абсолютный путь Windows (HIGH).**
  `resolve_path` не отбрасывал абсолютные пути: `/C:/Windows/win.ini`,
  `/D:/…`, NTFS-ADS (`file:stream`) открывали произвольные файлы на диске
  (вектор drive-by из браузера при `Access-Control-Allow-Origin: *`).
  Теперь сегменты с `:` отбрасываются, проверяются `is_absolute()`,
  `Component::Prefix/RootDir` и `starts_with(root)`. Добавлены регрессионные
  тесты (`tests/security.rs`, 9/9).
- **Безопасность: MIME SPA-фолбэка.** `{path}` без расширения отдавался как
  `application/octet-stream` (браузер скачивал файл вместо рендера). Теперь
  MIME считается по фактически отданному файлу; резолвинг `{path}` →
  `{path}.html` → `{path}/index.html` → 404.
- **Безопасность: Host-валидация.** Чужой `Host` (DNS-rebinding) отклоняется
  421; принимаются только `localhost`/`127.0.0.1`/`[::1]`.
- **Безопасность: методы.** Не-`GET`/`HEAD` на статике → 405; нераспознанный
  метод в прокси → 405; `Transfer-Encoding: chunked` → 411.
- **Безопасность: 404 вместо blanket-SPA.** Неизвестные пути (`/.git/config`,
  произвольные) дают честный 404.
- **Безопасность: прокси-префикс.** `/v1/` вырезается ровно один раз
  (`strip_prefix`), сегменты `..` в остатке → 404.

### Notes

- Версия совпадает с текущей версией крейта (`0.1.0`); отдельного
  SemVer-выпуска крейт не имел. См. также корневой `CHANGELOG.md` workspace'а
  (версия пакета `nx-app`).
